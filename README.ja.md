# XAssistant Mac

[简体中文](README.md) | [繁體中文](README.zh-Hant.md) | [English](README.en.md) | **日本語** | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md)

macOS のキーボード・マウス操作をローカルに記録し、3D ヒートマップ付きのアニメーション動画を書き出すツールです。

[xuhk/XAssistant](https://github.com/xuhk/XAssistant) の機能とアイデアをもとに、Swift でネイティブに再実装しました。非公式の macOS 版であり、元の作者との提携関係はありません。上流の Windows ソースコードや素材はコピーしていません。[MIT ライセンス](LICENSE)で公開しています。

## 機能

- メニューバーからバックグラウンドで操作を記録し、日別の統計とキーボードヒートマップを表示。
- 内蔵・外付けキーボードを検出。MacBook とテンキー付き Mac キーボードの配列を用意し、手動選択にも対応。
- 開始・終了日時を選択。「最初」「現在」のショートカットを使用可能。
- キーの押下アニメーションと累積ヒートマップを 1080p・30 fps の MP4 に書き出し、「ダウンロード」に保存。操作のない時間を自動で短縮。
- マウスを含めるか選択でき、速度は 0.5×〜256×（128×を含む）に対応。
- 色の上限を再生時点の最大累積回数に追従させるか、選択期間の最終最大回数に固定。
- 最後のヒートマップを 5 秒間表示しながら、カメラをゆっくり回転。
- 各物理キーに異なる音色を割り当て、押下に同期して再生。キーボード、メカニカル、ソフト、無音から選択可能。

## インストール

**Apple Silicon Mac と macOS 13 以降**が必要です。配布済みアプリの利用に Xcode は不要です。

- **直接ダウンロード：** [最新リリース](https://github.com/nope-gao/XAssistant-Mac/releases/latest)から `XAssistant-Mac-arm64.zip` を取得し、展開した **XAssistant Mac.app** を `~/Applications` に移動します。
- **ターミナルでインストール・更新：** 実行中のアプリを終了してから、次を実行します。

```bash
curl -fsSL https://raw.githubusercontent.com/nope-gao/XAssistant-Mac/main/install.sh -o /tmp/xassistant-install.sh && bash /tmp/xassistant-install.sh
```

スクリプトは最新リリースを取得し、SHA-256 と既存アプリの署名要件との互換性を確認します。互換性がない更新は置き換え前に停止します。確認後、sudo を使わず `~/Applications` にインストールし、記録データは保持します。アプリの ZIP が添付されたリリースが必要です。GitHub が自動生成する Source code ZIP はアプリではありません。

既存の v0.4.0 配布版は ad-hoc 署名で、Apple の公証を受けていません。macOS が起動をブロックする場合は、配布元を確認したうえで「システム設定 → プライバシーとセキュリティ → このまま開く」を使用してください。その後、以下の手順で入力監視を許可します。

## 表示言語

初期設定は「システムに従う」です。macOS の優先言語リストを順に確認し、対応する言語を選びます。対応言語は **简体中文、繁體中文、English、日本語、Español、Français、Deutsch**。一致する言語がなければ英語を使用します。ウィンドウ下部で手動選択や「システムに従う」への復帰ができ、設定は保存されます。

画面、メニュー、表示済みの状態メッセージ、日時・数値、マウスのラベル、機能キー名、動画字幕に選択言語を適用します。英字キーは物理 ANSI 配列のままです。動画には書き出し開始時の言語を使い、書き出し中の手動切り替えは無効になります。OS の権限ダイアログやシステムエラーの詳細は macOS が言語を管理します。

## 動画の音

「キーボード」（既定）、「メカニカル」、「ソフト」、「無音」を選択できます。各物理キーには固有の短い音色があり、押した瞬間だけ、押下を表示する最初のフレームに合わせて再生します。高速再生で密集した操作音は重ねてミックスします。マウスを除外するとクリック音も除外され、最後の 5 秒間は静かに表示します。

音はローカルで合成します。マイクや実際のキーボード録音、外部音素材は使いません。有音の動画には 48 kHz AAC トラックを含め、無音では音声トラックを生成しません。

## ソースからビルド

Xcode Command Line Tools が必要です。ビルドスクリプトは ARM64 アプリのみを生成します。対応対象のすべての macOS バージョンで検証済みではありません。

開発ツールが未導入の場合のみ最初のコマンドを実行してください。プロジェクトディレクトリでビルドすると、署名の確認と組み込みテストも実行されます。インストール前には既存アプリを終了してください。

```bash
xcode-select --install
bash build.sh
mkdir -p "$HOME/Applications"
ditto "dist/XAssistant Mac.app" "$HOME/Applications/XAssistant Mac.app"
open "$HOME/Applications/XAssistant Mac.app"
```

既定のローカルビルドは ad-hoc 署名です。Developer ID 署名や公証済みのビルドではなく、置き換えると既存の権限が失効する可能性があります。

## 使用方法と権限

初回起動後、「システム設定 → プライバシーとセキュリティ → 入力監視」で、インストール先の **XAssistant Mac** を許可し、アプリを終了して開き直します。キーボードとマウスを操作し、最新の記録日時と回数が実際に更新されることを確認してから書き出してください。

再ビルドやアプリの置き換えにより権限が失効する場合があります。スイッチがオンでも記録されない場合は、アプリを終了して次を実行します。

```bash
tccutil reset ListenEvent local.jasongao.xassistantmac
```

インストール済みアプリを入力監視に再追加し、許可してから再起動します。このコマンドは本アプリの入力監視権限のみをリセットします。

期間、速度、マウスの有無、ヒートマップの方式、音を選び、「ダウンロードに書き出す」をクリックします。記録が存在しない期間の操作は復元できません。

## ローカルデータとプライバシー

データは `~/Library/Application Support/XAssistantMac/` に保存します。アプリによるアップロードやテレメトリーはありません。インストーラーはリリースを取得するため GitHub に接続します。

アニメーション再生のため、押下・解放時刻、物理キー識別子、デバイス情報、イベント順序を保存します。アプリ名、Bundle ID、使用時間も記録します。入力メソッドの確定文字列、ウィンドウタイトル、URL、マウス座標は読み取りません。**キーとその順序から入力内容を推測できる場合があります。記録は機密データとして扱い、データディレクトリを公開しないでください。**

## 既知の制限

- 主に ANSI 配列に対応。ISO/JIS は未完全対応で、すべての他社製デバイスを自動検出できるとは限りません。
- Fn、メディアキー、セキュア入力中の操作は完全に記録できない場合があります。Touch ID は通常のキー押下として記録しません。
- 複数キーボードの同時使用では入力元の識別に制限があります。長押しの自動リピートは独立した押下として数えません。
- SceneKit、Metal、AVFoundation で動画を直接生成します。Blender は不要です。

## 新しいリリースの公開（メンテナー向け）

既存の v0.4.0 は ad-hoc 署名です。入力監視のオン・オフだけでは古い署名要件が残り、オンでも記録できないことがあります。今後の正式リリースは**固定の Developer ID Application 署名アイデンティティを必須**とし、証明書がなければ公開を停止します。

GitHub Actions Secrets に `SIGNING_CERTIFICATE_BASE64`（P12 の Base64）、`SIGNING_CERTIFICATE_PASSWORD`、`SIGNING_IDENTITY` を設定します。証明書の秘密鍵をリポジトリへコミットしないでください。ワークフローは一時キーチェーンに取り込み、終了時に削除します。更新には同じ署名アイデンティティを使い続けます。ad-hoc から Developer ID への初回移行時は、一度の再許可が必要です。

`build.sh` のバージョンとビルド番号を更新してコミットし、対応するタグをプッシュします。

```bash
git tag v0.4.1
git push origin main --tags
```

main へのプッシュで翻訳、操作タイミング、実際の音声・動画エンコードを検証します。タグの検証に成功すると、アプリ ZIP とチェックサム付きリリースを公開します。次回以降は新しいバージョン番号を使用してください。ローカルに証明書を導入したうえで `SIGNING_IDENTITY="Developer ID Application: …" bash package.sh` を実行し、`dist/XAssistant-Mac-arm64.zip` と `dist/SHA256SUMS` を手動添付することもできます。

`ALLOW_ADHOC_PACKAGE=1 bash package.sh` はローカルテスト専用です。権限を保持する更新として公開してはいけません。固定パスと Bundle ID だけでは ad-hoc 署名の変化を解決できません。[Apple の署名要件とプライバシー権限の説明](https://developer.apple.com/documentation/technotes/tn3127-inside-code-signing-requirements)を参照してください。
